# Sanug Teknoloji

Sanug Teknoloji is a software company based in Fethiye, Türkiye. We build custom software, SaaS platforms, games and mobile applications, and we run a dedicated Web3 and blockchain practice. Our own location-based and augmented reality products run on the same stack we deliver to clients, with server-side logic and security built in from day one.

## What we do

### Software Development
Custom web applications, backend services and databases, from architecture and data modelling to deployment and long-term maintenance.

### SaaS
Cloud platforms delivered as a service, with user management, admin panels and real-time data.

### Game Development
Mobile games built with Unity, including location-based and augmented reality gameplay. Our own title, Antiq World, is a location-based game in the design stage, launching on Android first and then iOS.

### Mobile Applications
Android and iOS applications with maps, geolocation, social sign-in and server-side validation.

### AI Integration
Integration of machine learning models and large language models into products and business workflows, from model selection to production deployment.

### Web3 and Blockchain
Web3 development and consulting across smart contracts, NFT, DeFi, DAO and GameFi projects, together with metaverse and IoT integrations. We design token and contract architectures, develop and audit smart contracts, and connect on-chain components with conventional backends.

## Technology

Unity, C#, TypeScript, React, PostgreSQL, Supabase, Cloudflare, GIS and map tile pipelines, Solidity and smart contract tooling.
